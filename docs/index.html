VerseSplitterAI

Standalone tooling for generating Quran page and verse boundary markers from full-surah recitations. It is built for batch processing multiple reciters and producing clean JSON marker data for downstream apps.

1Ayah Website Android App

What It Does

  • Generates page markers based on Madani page boundaries
  • Generates verse markers from word-level transcription alignment
  • Processes multiple reciters from a shared folder structure
  • Caches timestamps per reciter to avoid unnecessary retranscription
  • Supports optional MP3 metadata tagging for source audio

Expected Input

Recitations are organized by reciter and surah number:

recitations/
	alafasy/
		001.mp3
		002.mp3
		...
	luhaidan/
		001.mp3
		002.mp3
		...

Setup

Install project dependencies with uv. System ffmpeg and ffprobe are required.

uv sync

Usage

uv run python marker_generator.py
uv run python marker_generator.py --reciter alafasy
uv run python marker_generator.py --reciter alafasy --surah 78-114
uv run python marker_generator.py --reciter alafasy --mode pages
uv run python marker_generator.py --reciter alafasy --mode verses

Output

Generated marker files are written per reciter and per mode:

markers/
	alafasy/
		pages/
			001.json
		verses/
			001.json

Examples

A bundled page-by-page example set is included under docs/examples/page_by_page/alafasy/.

Use it as a reference for page-level naming, sample assets, and downstream playback integration. 

docs/examples/page_by_page/alafasy/
	page001-001000.mp3
	page002-002000.mp3
	...
	page604-114000.mp3

Metadata Tagging

Use the tagging script to add title, artist, album, track number, genre, and cover art to source MP3 files.

uv run python tag_mp3s.py recitations/alafasy \
	--reciter "Mishary Rashid Alafasy" \
	--cover resources/1ayah-logo.png
